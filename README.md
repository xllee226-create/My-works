# 🌟 精选项目

## 01｜萌宠星探————基于个性化选宠推荐与后续照料智能体

**项目类型：**【产品设计】  
**项目时间：**【2025.03—2025.06】  
**我的职责：**【参与数据获取挖掘、产品设计、Prompt设计等工作】

### 项目介绍

国内宠物经济规模持续扩张，但大量新手因盲目选宠、人宠生活不匹配引发弃养问题，现有平台信息杂乱、缺少个性化科学匹配工具。本项目打造RAG垂类AI智能体 “萌宠星探”，通过AI分析用户性格、居住条件、作息、预算，科学匹配适配猫狗品种，同时提供品种饲养指南、宠物图片识别能力，降低冲动养宠概率，提升人宠契合度，还可对接宠物店、领养机构实现B端落地。
区别于普通宠物资讯平台、海外单一测评 AI，产品集人格匹配推荐、宠物图像识别、智能问答、可嵌入部署四大能力：依托多维匹配算法做个性化选宠，支持上传图片识别宠物品种，结合本地宠物知识库 + 联网搜索保证回答专业准确，可嵌入小程序、领养平台、宠物电商使用。

### 我的工作

- 【负责的具体工作一】协助队长获取猫狗数据
  结合预调研结果（绝大多数用户饲养的是猫狗），负责确定爬取目标网站（大型宠物网站、论坛等），利用 Python 编写爬虫（接口请求爬取 + 页面模拟操作自动化）爬取猫、狗相关数据，包括宠物品种信息、论坛文章、饲养方法及法律法规等内容；对爬取结果进行初步整理与核对，为后续知识库构建提供原始数据基础。
- 【负责的具体工作二】进行数据分层和数据预处理
  将爬取到的 HTML 文件进行结构化预处理：去除冗余信息与无效内容，把分散、重复的数据合并整合，并配置大模型分段策略对数据进行分层、分段和打标处理（区分宠物基本信息、论坛/文章内容等层级）；将预处理后的结构化文本投喂到扣子(coze)平台资源库构建本地知识库，为智能体检索问答提供标准化、可召回的数据支撑。
- 【负责的具体工作三】参与智能体效果评测与优化反馈
  利用扣子平台效果评测工具，构建 100 个常用问题，围绕准确性、需求满足性、丰富度、精炼性、适用性五个维度对智能体进行打分评估（总分 400 分，团队最终得分 333 分，处于"良好"档位）；根据评测结果整理问题反馈，协助优化提示词与调用逻辑，提升意图识别率和流程闭环质量；同时整理应用场景案例（个性化推荐、图片识别）与评测数据，为产品落地和推广准备素材。
- 【与团队协作或推进项目落地的工作】
  参与需求收集环节的用户访谈（覆盖新手养宠、现有宠物主、宠物行业人员三类对象，共约 15–20 人），将访谈与数据挖掘结果转化为三类核心需求（辅助决策、兼容性、长期喂养），并参与竞品分析与市场定位讨论；协同完成「知识库搭建—工作流设计—智能体配置」的整体流程闭环，包括多模态输入、意图识别、记忆管理与联网兜底等模块的联调测试；参与撰写产品设计报告与演示材料，并结合宠物经济市场数据（2024 年规模超 3000 亿元）梳理推广与应用展望（电商导购、领养平台、用户画像等），为项目落地提供支撑。

## 02｜Cool C.A.I.—— An experiential game that simulates working in a real big factory

**项目类型：**【模拟产品岗位的游戏】  
**项目时间：**【202608】  
**我的职责：**【游戏测试、游戏制作】

### 项目简介

**Cool C.A.I.**是一款可在浏览器上玩的垂直游戏，它将经典的时间管理游戏重新构想为一个现代、高压的企业产品环境。您扮演一个项目经理的角色，负责将模棱两可的请求转换为跨产品、数据、工程和增长的已交付工作，同时管理压力、会议、依赖关系和有限的容量。
这是一个通过可玩系统演示AI产品管理思想的组合项目：问题框架、跨功能优先级、AI工作流设计、度量、权衡和人性化操作。基于2007年的单机游戏Miss Management的游玩方式进行二次创新，更加结合当今时代工作强度和工作内容调度的游戏。

### 主要亮点

- 【亮点一】游戏沉浸式体验足，员工的压力值随时变化，结合GTA游戏的时间流逝特点，让每一天的模拟体验充满真实感。
- 【亮点二】游戏多场景融合，充分结合大型公司经常临时开例会或开大量例会的特点，将一个忙前忙后的项目经理（产品经理）的真实形态展现出来。
- 【亮点三】突出加班现象，真实社会中经常存在加班现象，通过一种“乌托邦”式的申请加班机制，增加游戏的难度和现实的匹配度。

### 代表项目

#### 职达27——基于管理科学与工程专业的27秋招推荐系统

求职者花费大量时间浏览岗位、修改简历和广泛投递，但很难知道自己被默拒的原因，也不知道AI面试在哪一环节失分。需要一个能减少无效投递、解释岗位适配度并协助执行投递的工具。
基于此，本项目面向2027届财经高校管理科学与工程专业本科及硕士的岗位适配与批量投递助手。系统发现并去重真实岗位，先筛除学历、届别、城市、薪资、到岗时间等硬门槛，再结合简历判断“直接可投、修改后可投、不建议投”，生成只基于真实经历的定制建议；用户确认后进入投递队列，Demo模拟表单填写、提交和进度记录，不实际登录招聘平台。

**主要功能：**

- 【功能一】主要做2027届秋招，实习推荐不超过20%；
- 【功能二】正式岗9000元门槛确认有效，实习岗不应用该门槛；
- 【功能三】2000岗浏览和1500—2000份投递为求职高峰期的周投递量。

**技术与工具：**

`HTML` · `CSS` · `JavaScript` · `Vue / React` · `Figma`
