### 项目介绍

国内宠物经济规模持续扩张，但大量新手因盲目选宠、人宠生活不匹配引发弃养问题，现有平台信息杂乱、缺少个性化科学匹配工具。本项目打造RAG垂类AI智能体 “萌宠星探”，通过AI分析用户性格、居住条件、作息、预算，科学匹配适配猫狗品种，同时提供品种饲养指南、宠物图片识别能力，降低冲动养宠概率，提升人宠契合度，还可对接宠物店、领养机构实现B端落地。
区别于普通宠物资讯平台、海外单一测评 AI，产品集人格匹配推荐、宠物图像识别、智能问答、可嵌入部署四大能力：依托多维匹配算法做个性化选宠，支持上传图片识别宠物品种，结合本地宠物知识库 + 联网搜索保证回答专业准确，可嵌入小程序、领养平台、宠物电商使用。

# 🧭 我的工作方式

面对一个新的任务，我通常会按照以下方式推进：

1. 理解任务背景与真实目标
2. 收集信息并拆解核心问题
3. 制定内容、设计或技术方案
4. 快速完成初版并进行验证
5. 根据反馈持续修改和完善
6. 对项目过程与最终结果进行复盘

我重视结果，也重视沟通、协作以及项目过程中的细节。
